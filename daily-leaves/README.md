# 日拾书页 · Daily Leaves

> 每天拾起一页，留下读过的痕迹。

这里记录每天的阅读与思考。书籍、文章、论文、技术文档，都可以成为一页的起点。

不要求每篇都写得完整，也不把记录变成打卡负担。读到有触动的地方，就写下它，以及它为什么值得记住。

## 怎样记录

复制 [记录模板](TEMPLATE.md)，按年份归档，以 `YYYY-MM-DD.md` 命名。例如，第一篇记录可以放在 `2026/2026-11-02.md`。

一篇记录优先回答三个问题：

- **读了什么？** 留下标题、作者与来源，方便以后重新找到。
- **理解了什么？** 用自己的话记下关键观点，区分作者的观点与自己的判断。
- **留下了什么？** 一个启发、一个疑问，或一个想尝试的小行动。

模板只是起点，按当天内容删改即可；同一天的多篇阅读可以重复使用「阅读条目」部分。

## 如何回看

按年份目录与文件名中的日期查找，也可以用仓库搜索寻找标题、关键词或标签。等记录积累到需要时，再整理主题索引。
