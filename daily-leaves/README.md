# 日拾书页 · Daily Leaves

> 每天拾起一页，留下读过的痕迹。

这里存放可以独立阅读的文章导读与分析。书籍、文章、论文、技术文档，都可以成为一页的起点。

每篇先讲清问题、背景、核心机制与结论，再补充例子、限制和延伸思考。可以先看导读建立理解，再回到原文核对细节；也可以只读导读，掌握主题的主要脉络。

AI 整理的分析与读者本人的感想分开表述，不把生成内容写成读者已经形成的观点。原文主张、补充解释与尚未验证的结果也需要明确区分。

不要求每篇都写得完整，也不把记录变成打卡负担。读到有触动的地方，就写下它，以及它为什么值得记住。

## 怎样记录

复制 [记录模板](TEMPLATE.md)，按年份归档，以 `YYYY-MM-DD.md` 命名。例如，第一篇记录可以放在 `2026/2026-11-02.md`。

文件名使用阅读日期；补整理的文章另外标明整理日期。每篇优先回答三个问题：

- **读了什么？** 留下标题、作者与来源，方便以后重新找到。
- **怎样理解？** 从背景讲到核心机制，用例子说明关键关系，区分作者主张与整理者分析。
- **怎样判断？** 说明证据、适用条件与限制，留下可继续追问的问题。

模板只是起点，按当天内容删改即可；同一天的多篇阅读可以重复使用「阅读条目」部分。
